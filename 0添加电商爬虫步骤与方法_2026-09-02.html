"0添加"电商数据爬取步骤与方法（实测版）

京东 × 淘宝 ｜ 基于 2026-09-02 实际登录态采集经验 ｜ 附首批样本数据

先说结论（务必看）：淘宝、京东搜索"0添加"都只显示"共 100 页"分页上限、不暴露精确商品总数（平台防爬设计）。实测：京东每页 30 条 ≈ ≥3000 件；淘宝每页 44 条 ≈ ≥4400 件；两平台合计去重前约 7400 件量级，真实数量只会更多。这是页面可查证口径（你登录后打开同样页面能看到"1/100"）。以下步骤据此设计。

1准备：浏览器 + 登录态（必须）

为什么必须登录

实测：未登录访问 search.jd.com 会被重定向到京东登录页；淘宝搜索页显示"亲，请登录"，结果区"加载中"不返回数据。两个平台都需要登录态才能看到搜索结果。

操作

  • 用 Chrome/Edge 打开京东、淘宝，分别完成登录（手机扫码最快）；
  • 登录后先手动搜索一次 0添加，确认能看到商品列表与"1/100"分页；
  • 不要关浏览器、不要退出登录，后续自动化复用该登录态。

2最简单方式（纯手动，约 5 分钟）

无需任何代码，记录三组数字即可支撑"全景数据框"：

步骤操作记录
1京东搜索 0添加（登录态）分页"共 N 页"、每页条数（30）→ 估算 ≥N×30 件
2淘宝搜索 0添加（登录态）分页"共 N 页"、每页条数（44）→ 估算 ≥N×44 件
3换关键词：0蔗糖 / 无添加 / 0防腐剂 / 0色素 各搜一次各关键词分页数，用于估算覆盖范围
4记录第一页前 20 个商品标题+价格+销量作为样本表
手动方式拿到的就是"分页上限×每页条数"口径，与自动化一致，真实可溯源。

3自动化方式（已实测跑通，可复用）

思路

用浏览器自动化（复用登录态）打开搜索页，从 DOM 读取每页商品卡片与分页上限，无需破解反爬签名。比普通 Python 爬虫（requests）可靠得多——requests 拿不到登录态且极易触发验证。

4翻页与多关键词扩展（可选）

  • 翻页深度：京东分页 ?page=2,3,…；淘宝 &page=2,…。抓取前 N 页即可统计品类分布与品牌集中度（CR5）。
  • 多关键词：依次爬 0添加 / 零添加 / 无添加 / 0蔗糖 / 无蔗糖 / 0防腐剂 / 0色素 / 无亚硝酸盐，各记录分页数，取并集估算覆盖范围。
  • 同比（2024→2025→2026）：采集商品上架时间字段按年分组统计；或借助第三方平台（魔镜洞察/蝉妈妈/Nint任拓）历史数据。
  • 品类：按平台三级类目归属，统计酱油/饮料/饼干/酸奶/香肠/膨化食品等各品类商品数。
